# Storage — Tuze шифрланған чаттары

Windows ноутбукте жұмыс істейтін жергілікті Qwen3 чат интерфейсі. Чаттар осы репозиторийге синхрондалғанда әрқайсысы **өзінің бір JSON файлына** түседі:

```text
Storage/
└── chats/
    ├── chat_001.json
    ├── chat_002.json
    └── ...
```

`chats/.gitkeep` — бос қалтаның белгісі. Шынайы чат файлы чат жасалып, GitHub синхрондалғаннан кейін пайда болады. `id` — чаттың өзгермейтін UUID-і; қайта ашып жазсаңыз, сол чаттың сол файлы жаңарады. Екі бөлек чаттың ID-і бір файл атауына түссе, жергілікті чат жаңа бос нөмірге көшеді, екіншісінің үстіне жазылмайды.

## Іске қосу

1. Репозиторийді ZIP ретінде жүктеп, толық ашыңыз немесе `git clone` жасаңыз.
2. Windows жүйесінде Ollama және мәтінге арналған `qwen3:4b-instruct` моделі орнатылсын. Фотоны AI талдауы үшін бөлек `qwen3-vl:4b-instruct` моделін `ollama pull qwen3-vl:4b-instruct` командасымен орнатыңыз. Ол орнатылмаса фото чатта сақталады және көрінеді, бірақ модель фотодағыны талдамайды. Қолданба модельдерді автоматты түрде жүктемейді.
3. `Start-Storage.cmd` файлын екі рет басыңыз. Браузерде жергілікті адрес ашылады.
4. Кемінде 12 таңбалық **тұрақты кілтсөзді** енгізіп, **Ашу** басыңыз. Келесі жолы чаттарды ашуға дәл осы кілтсөз керек. Ұмытсаңыз, шифрды ашу мүмкін болмайды.
5. GitHub-қа синхрондау үшін `Storage` репосына ғана рұқсаты бар fine-grained token жасаңыз: Repository access — **Only select repositories → Storage**; Repository permissions — **Contents: Read and write**. Токенді тек жергілікті қолданбаға енгізіп, **Ашу**, кейін **GitHub синхрондау** басыңыз. Токенді чатқа, репозиторийге немесе скриншотқа жазбаңыз. [GitHub нұсқаулығы](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens).

Токенсіз де жергілікті чат істейді. Интернет/токен жарамсыз болса, хабарламалар ноутбукте қалады және синхрондау қатесі көрінеді. Кейін қайта синхрондаңыз. Ашық қара терминал терезесін жапсаңыз, сервер тоқтайды.

## Чат және Tuze

**Жіберу** батырмасы хабарламаны алдымен жергілікті шифрланған файлға сақтайды, содан кейін Ollama-ға жібереді. Жауап келген соң ол да сол чат файлына қосылады. Чатқа қайта кіргенде осы файл оқылады. **📷 Фото қосу** арқылы JPEG/PNG суретін тіркей аласыз; браузер оны JPEG түріне қысып, сол чаттың шифрланған JSON файлына енгізеді. Фотоны AI-ға түсіндіру үшін орнатылған vision модель пайдаланылады; мәтіндік `qwen3:4b-instruct` фотоны көре алмайды. **Tuze · өзгерісті көру** батырмасы жіберілмеген мәтіннің «Бұрын» және «Tuze ұсынған» нұсқаларын, өзгерген жерін және ескертулерін көрсетеді. Мәтін тек **Өзгерісті қолдану** басылғанда ауысады.

## Файл пішімі мен қауіпсіздік

Репозиторий **public**. Файл атауы, чат UUID-і және уақыт белгісі көрінеді. **Атау мен хабарламалар шифрланған**. GitHub-тағы бір чат файлының түрі:

```json
{
  "schema_version": 2,
  "id": "<chat-uuid>",
  "filename": "chat_001.json",
  "updated_at": "<ISO timestamp>",
  "version": "<revision-uuid>",
  "encryption": {
    "algorithm": "AES-256-GCM",
    "kdf": "PBKDF2-HMAC-SHA256",
    "iterations": 600000,
    "salt": "<base64>",
    "nonce": "<base64>",
    "ciphertext": "<base64; encrypted title, messages and IDs>"
  }
}
```

Браузер Web Crypto арқылы әр сақтауда жаңа salt пен nonce қолданып шифрлайды; кілтсөз бен GitHub токені файлға сақталмайды. Жергілікті шифрланған файлдар `%LOCALAPPDATA%\TuzeStorage\chats` ішінде атомарлық ауыстырумен жазылады; бұрынғы нұсқалар `.bak.*` болып қалады. GitHub жаңартуы файлдың SHA мәнін тексереді. Қайшылықта бір чаттың хабарламалары UUID бойынша біріктіріледі; бір UUID-тің екі түрлі мазмұны анықталса сақтау тоқтайды. Бір чаттың файлын басқа чаттың үстіне жазуға болмайды.

Кілтсөз әлсіз болса, public файлдарға қарсы құпиялылық төмендейді. Кілтсөзді қауіпсіз сақтаңыз және жергілікті қалтаның резерв көшірмесін жасаңыз. Бір файлға көп фото қосылса, GitHub өлшем шегіне жетіп, синхрондау тоқтауы мүмкін; жергілікті нұсқа сақталады және қате көрсетіледі. Диск істен шығуы, кілтсөзді жоғалту немесе GitHub синхрондауы аяқталмай қалу тәуекелін еш бағдарлама толық жоя алмайды. Git тарихы мен жергілікті `.bak.*` нұсқалары қалпына келтіруге көмектеседі. Репозиторийді Private ету қосымша қорғаныс береді.

## Тексеру

Дайындаушыға Node.js бар болса: `node --test tests/*.test.mjs`. Қолданбаны іске қосу үшін Node.js немесе Python қажет емес. Нақты Windows PowerShell 5.1 іске қосылуын және GitHub токенімен жазылуын пайдаланушы ноутбугінде тексеру керек. Токен мен кілтсөзді тесттерге енгізбеңіз.
