# TUZE — gpt-oss:20b + Logo&AI + GitHub + кодты чатта көру

**Windows + Ollama + gpt-oss:20b.** ChatGPT үлгісіне ұқсас жеке чат интерфейсі: сол жақта чат тарихы мен іздеу, ортасында диалог, төменгі бөлікте хабарлама енгізу, фото тіркеу, көшіру, қараңғы/жарық режим және TUZE жазуды түзету ұсыныстары.

## Сурет жасау

1. ZIP ішіндегі `Storage/Setup-Images.cmd` файлын **бір рет** іске қосыңыз. Ол ресми [stable-diffusion.cpp Windows CPU жинағын](https://github.com/leejet/stable-diffusion.cpp/releases) (18 МБ) және ресми [SD-Turbo салмағын](https://huggingface.co/stabilityai/sd-turbo) (5,21 ГБ) жүктеп, SHA256 арқылы тексереді. Файлдар Windows пайдаланушысының `LocalAppData/TuzeStorage/image` қалтасында қалады; ZIP-ке немесе GitHub репозиторийіне қосылмайды.
2. Ескі TUZE терезесін жауып, `Start-Storage.cmd` қайта ашыңыз. Чаттағы **🖼 Сурет** батырмасын басып, керегін жазыңыз да жіберіңіз.
3. `gpt-oss:20b` сипаттаманы ағылшын тіліне қысқаша аударады; SD-Turbo 512×512 PNG суретін CPU-де жасайды. Нәтиже чатта көрсетіледі, JPEG-ке сығылып **сол чаттың бір JSON файлына** сақталады. **↓ Фото** арқылы сақталған суретті жүктей аласыз.

**Модель суреті чат ашылғанда өздігінен жүктелмейді.** Орнату тек `Setup-Images.cmd` басылғанда басталады. Видео карта әлсіз болса, CPU-де бір сурет бірнеше минут алуы мүмкін. `gpt-oss:20b` сурет моделінің орнын баспайды; 5,21 ГБ бос орын мен қосымша жедел жад керек. Суреттер Private GitHub репозиторийіндегі чат JSON-ына түседі, қосымша end-to-end шифрлау жоқ.

Бір чат файлының шегі 8 МБ. Суреттер көп жиналғанда жаңа чат ашыңыз; ескі чат сол күйі сақталады.

## Іске қосу

1. ZIP файлын **толық** ашыңыз. Ішіндегі `Storage` қалтасын ашыңыз.
2. Компьютерде **Ollama** және **gpt-oss:20b** болуы қажет. `ollama list` ішінде `gpt-oss:20b` көрінуі тиіс. Фото талдау қажет болса, `ollama pull qwen3-vl:4b-instruct`.
3. Бір рет **GitHub CLI** орнатыңыз: Windows PowerShell-де `winget install --id GitHub.cli --source winget`. Git орнату қажет емес: TUZE GitHub API арқылы сақтайды. Егер GitHub CLI бұрын орнатылған болса, TUZE оның орнын Windows-та өзі іздейді.
4. `Start-Storage.cmd` екі рет басыңыз. Жаңа GitHub аккаунтыңыз болмаса, кіру бетінде **GitHub аккаунтын тіркеу** сілтемесі бар — ресми GitHub сайтында тіркеліңіз. Ашылған TUZE чаттағы **GitHub арқылы кіру** батырмасын басыңыз. Жаңа PowerShell терезесі GitHub-тың ресми браузер авторизациясын ашады; GitHub сұраса бір реттік кодты сол **GitHub сайтында** енгізесіз. Сәтті кірсеңіз TUZE аккаунтты өзі таниды.
5. Бұдан кейін чаттар `Tuze-Private-Chats` атты **жеке (Private)** GitHub репозиторийінде автоматты сақталады. Ол аккаунтта жоқ болса, TUZE өзі жасайды. Токен, кілтсөз, қалпына келтіру кілті, шифрлау режимі сұралмайды. Git executable керек емес; TUZE тек GitHub CLI авторизациясын пайдаланады. GitHub CLI-де браузерге кіру енді `--git-protocol` жалауын қолданбайды.

**Маңызды:** Бастапқы `jjjjjjjjjjjjjjae-hub/Storage` репозиторийі Public. Жаңа нұсқа оған енді ешқандай чат жазбайды. Жаңа жеке репозиторий дәл сол аккаунт ішінде автоматты жасалады. Ол қандай да бір себеппен Public болып тұрса TUZE чаттарды оған жарияламай, сақтауды тоқтатады. Репозиторий ішіндегі жаңа чат JSON-дары қосымша end-to-end шифрланбайды: **Private репозиторийге және GitHub аккаунт қауіпсіздігіне сенім қажет**. Репозиторийді жарияламаңыз. GitHub құпия жазбалары үшін қосымша қорғаныс немесе толық E2E шифрлау қажет болса, бұл нұсқаның қауіпсіздік моделін таңдамаңыз.


## Әр хабарламаның астындағы «Түзету» (v4)

- **Пайдаланушының да, TUZE жауабының да астында** «✦ Түзету» бар. Түймені басқанда gpt-oss:20b сол хабарламаның өзін тексереді.
- Хабарламаның дәл астында **Алдыңғы нұсқа / Кейінгі нұсқа** және **Өзгерісті қолдану / Бас тарту** көрсетіледі. Мақұлданған өзгеріс жергілікті чатқа сақталып, GitHub Private репозиторийімен синхрондалады. Бастапқы мәтін `original_content` арқылы сақталады.
- Басқаның түзетуін ескі хабарламаға үнсіз жазбайды: синхрондау бір хабарламаның түзетілген және бастапқы нұсқасын дұрыс біріктіреді.
- Мәтіндік түзету Ollama жергілікті gpt-oss:20b моделін қажет етеді; GitHub ол тек чат сақтайды. Түзету сәтсіз болса, қате тікелей хабарламаның астында көрінеді.

## Төменгі енгізу жолағындағы «Түзету» жұмыс істеуі үшін

- Мәтінді төменге жазыңыз. **✦ Авто** әдепкіде қосулы: TUZE мәтінді кідірістен кейін өзі тексереді. **Түзету** батырмасы бірден тексеруді бастайды.
- Нәтиже шыққан соң **Алдыңғы нұсқа / Кейінгі нұсқа** айырмашылығын көресіз. **Өзгерісті қолдану** түймесі ғана жазылған мәтінді ауыстырады; мағынасы өзгеруі мүмкін түзетулерді өзіңіз тексеріңіз.
- Түзету GitHub API-ден тәуелсіз: оны Ollama-дағы gpt-oss:20b моделі орындайды. Түзету бөлек Windows процесінде жүретіндіктен, сервер басқа HTTP сұрауларын қабылдай береді.
- «TUZE түзету қатесі» шықса, нақты қате төменгі жолда көрсетіледі. **Ollama іске қосылғанын** және `ollama list` ішінде `gpt-oss:20b` барын тексеріңіз.

## GitHub кіруі ашылмаса

1. `Start-Storage.cmd` арқылы ашылған чаттың **GitHub арқылы кіру** батырмасын басыңыз. Бұл үшін GitHub CLI орнатылған болуы керек.
2. «GitHub CLI табылмады» десе, PowerShell-ге `winget install --id GitHub.cli --source winget` енгізіңіз де, TUZE-ні қайта қосыңыз.
3. «Authentication complete» деген жазудан кейін Git табылмады десе де, GitHub авторизациясы сақталған болуы мүмкін. PowerShell-де `gh auth status` деп тексеріңіз. Егер авторизация сәтті болса, TUZE-ні қайта ашыңыз.
4. Репозиторийге рұқсат қатесі шықса, `gh auth refresh -h github.com -s repo` командасын ресми GitHub CLI ішінде орындап, TUZE-ні қайта ашыңыз.
5. Жаңа нұсқаны **ескі серверді тоқтатып**, ZIP ішінен толық ашылған файлдар арқылы іске қосыңыз. Әйтпесе браузердегі бұрынғы порттағы терезе ескі кодпен қалуы мүмкін. `TUZE_STORAGE_URL=...` жазуындағы мекенжайға кіріңіз.

Node.js сақтау/синхрондау тесттері және GitHub Actions ішіндегі Windows PowerShell 5.1 интеграциялық тесті mock Ollama-мен өтті. Нақты ноутбуктегі `gpt-oss:20b` жауабын және GitHub аккаунтымен кіруді осы ортадан тексеру мүмкін емес; оны өз компьютеріңізде іске қосып көріңіз.

## Чат тарихы

- Әр чат `chats/chat_001.json`, `chat_002.json`, т.б. файлда сақталады, әр жаңа хабарлама жергілікті ноутбукта сақталып, кейін GitHub-пен автоматты синхрондалады.
- Екінші Windows құрылғысында **сол GitHub аккаунтымен** кірсеңіз, жеке қоймадағы **жаңа v3 форматындағы чаттар** автоматты ашылады. Қосымша қалпына келтіру кілті керек емес.
- Офлайн кезде жергілікті чат сақталады, интернет қайта пайда болса синхрондалады. GitHub рұқсаты болмаса кіру экраны көрсетіледі.
- Бастапқы Windows пайдаланушысы профилінде ескі v2 шифрланған чаттар болса, сақталған **Windows DPAPI кілті** табылғанда олар көшіріледі; бастапқы шифрланған файлдың `.bak.*` сақтық көшірмесі қалады. Егер Windows профилінің DPAPI кілті жоғалған болса, тек GitHub аккаунты бұрынғы **ескі шифрланған** чаттарды аша алмайды — оларды ескі нұсқадағы қалпына келтіру кілтімен бастапқы құрылғыда ашу керек. Жаңа v3 чаттарға бұл кедергі жоқ.
- Ollama модельдері жергілікті орындалады; чат сұраулары модельге `127.0.0.1:11434` арқылы барады. **GitHub синхрондауы интернетті қажет етеді.**
- GitHub API синхрондауы үшін GitHub CLI аккаунт рұқсатын пайдаланады. `gh auth logout --hostname github.com` деп Windows PowerShell-де шықсаңыз, TUZE келесі тексеруде кіруді қайта сұрайды.

## Қауіпсіздік ескертпелері

- Токенді немесе құпия кілтті TUZE чат терезесіне енгізбеңіз. Ресми GitHub авторизациясын пайдаланыңыз. Қолданбаның жергілікті `/api/session` маршруты GitHub CLI беретін рұқсатты браузер скриптіне береді; компьютердегі басқа жергілікті процестерге және зиянды браузер кеңейтімдеріне қарсы толық қорғаныс емес. Компьютерді тек өзіңіз қолданған жөн.
- Акаунтқа кірген соң GitHub жеке қоймасын TUZE өзі дайындайды. Қоймаға жіберу алдында оның Private екені қайта тексеріледі.
- Фото жіберу мәтін моделінің фото талдай алатынын білдірмейді. Ол үшін бөлек vision модель қажет.
- Қосылған құрылғыдағы ескі файлдарды жоймаңыз; автоматты көшірілгеніне көз жеткізіңіз.

## Logo&AI — сұрақ қойып, gpt-oss:20b-ке түсінікті тапсырма дайындау (v5)

1. TUZE чатына қазақша ойыңды әдеттегідей жаз.
2. Хабарламаны жібермей тұрып, **✧ Logo&AI** батырмасын бас.
3. Ол `gpt-oss:20b` арқылы не түсінгенін қысқаша көрсетеді. Тапсырма түсініксіз болса, 1–3 қазақша сұрақ береді.
4. Жауаптарды толтырып, **«Жауаптарды ескеріп дайындау»** батырмасын бас. Сұраққа жауап бере алмасаң, бос қалдыра аласың.
5. Төмендегі **ағылшынша тапсырманы** тексеріп, қажет болса өңде де **«gpt-oss:20b-ге жіберу»** батырмасын бас.

Чатта **сен жазған бастапқы қазақша мәтін** сақталады; gpt-oss:20b-ге нақтыланған ағылшынша нұсқасы уақытша жіберіледі. Жауап қазақша беріледі. Бұл құрал gpt-oss:20b моделін қайта үйретпейді және интернеттегі басқа API-лерге жібермейді: сол жергілікті Ollama моделін екі қадамда пайдаланады. Нақтылаудың дұрыстығына 100% кепілдік жоқ; әсіресе белгісіз қысқартулар мен екіұшты сөйлемдерді қарап шық.

**Техникалық ақпарат:** `POST /api/logo/start` JSON `{ "stage": "analyze", "text": "...", "answers": [] }` және `GET /api/logo/result/<job_id>` қолданылады. Сұрақтарға жауап беріп, `stage: "build"` және `{ "question": "...", "answer": "..." }` нысандарын `answers` тізіміне беруге болады. Сұраулар фондық PowerShell worker арқылы жергілікті Ollama-ға жіберіледі, API кілті талап етілмейді.


## TUZE v6 — Кодты файл және чаттағы нәтижені көрсету

- `gpt-oss:20b` код жазғанда жауапта ` ```html filename="index.html" ` түрінде белгіленген файлдарды жасауға бағытталған.
- TUZE JavaScript жағында код блоктарын `.html`, `.css`, `.js`, `.py`, `.json` және басқа форматтарға бөліп көрсетеді. Әр файл үшін **↓ Файлды жүктеу** бар; **↓ ZIP** барлық файлды бірге береді.
- HTML жауаптың **◫ Нәтиже** терезесінде ештеңе жүктемей жұмыс істейді. `index.html` салыстырмалы `style.css` және `script.js` файлдарына сілтеме жасаса, олардың мазмұны автоматты кірістіріледі.
- Нәтиже бөлек `sandbox="allow-scripts"` iframe арқылы оқшауланады: оның `allow-same-origin` құқығы жоқ. Интернетке қосылатын скрипттер іске қосылмайды, сондықтан сыртқы кітапханаға тәуелді жобаның көрінісі шектеулі болуы мүмкін.
- Python/Java/басқа серверлік кодты браузерде орындау мүмкін емес: TUZE кодты файл түрінде көрсетеді, бірақ іске қосқандай етіп көрсетпейді.
- Файлдар жауаптың ішінен қайта қалпына келтіріледі: чат сақталса, файлдар да чатта сақталады. Бұл файлдарды компьютердің басқа қалтасына автоматты жазбайды.
- Басқа ZIP орнатқандағы сияқты, жаңа нұсқаны **бөлек қалтаға** ашып, `Storage/Start-Storage.cmd` іске қосыңыз.


## TUZE — gpt-oss:20b (осы жинақ)

- Модельдің нақты атауы: `gpt-oss:20b`. Басқа 4B моделі қажет емес.
- Ол `app/config.json` ішінде және іске қосатын `Start-Storage.ps1` тексерісінде бекітілген.
- Chat, Logo&AI, хабарлама астындағы Түзету бір жергілікті модельді қолданады.
- 20B баяу жауап беруі мүмкін, сондықтан чат тапсырмасы бөлек Windows PowerShell процесінде жүріп, интерфейс сервері жауап беріп тұрады.
- Автоматты түзету әдепкіде қосулы. Ноутбук баяуласа «✦ Авто» батырмасымен сөндіріп, «Түзету» батырмасын қажет кезде басыңыз.
- Коды ұзақ болса, чатта «Файлдар / Код / Нәтиже» сақталады; жауап көлемі `config.json` арқылы `num_predict: 3072`, `num_ctx: 4096` деп қойылды. Жады жеткілікті болса көбейтуге болады.
- Егер модель баяу болса, `ollama ps` және Windows тапсырмалар менеджеріндегі RAM-ды тексеріңіз. Модельді қосымша жүктеудің қажеті жоқ, егер ол `ollama list` ішінде болса.
- `gpt-oss:20b` сурет модель емес. Фото талдау үшін бөлек `qwen3-vl` қажет; қалған чат пен код жұмыс істейді.
- GitHub чат синхрондауы бұрынғыдай жұмыс істейді, жоба қоймасын ашық (Public) етпеңіз.

## Егер gpt-oss:20b жауап бермесе

`ollama list` — модельдің **орнатылғанын** көрсетеді. `ollama ps` — тек **дәл қазір жүктеліп тұрған** модельдерді көрсетеді: бос болса бұл қате емес.

1. Windows CMD: `ollama run gpt-oss:20b` және `Сәлем` деп жазыңыз. CLI-де жауап келмесе, бұл TUZE интерфейсінен емес — 13 ГБ модельді жүктеу/жедел жад мәселесі болуы ықтимал.
2. RAM тексеру: PowerShell: `Get-CimInstance Win32_ComputerSystem | Select-Object TotalPhysicalMemory` (байтпен). Task Manager > Performance > Memory бөлімінде ГБ көрінеді.
3. TUZE-де 20B бірден жауап бермесе, Ollama модельді жедел жадқа дайындап жатқанын көрсетеді. Бұл интернеттен қайта жүктеу емес. Жауап генерациясы басталғанда сөздер чатта біртіндеп пайда болады.
4. GitHub желілік сұраулары енді ЖИ жауабын бастаудан бұрын орындалмайды. GitHub синхрондау модельдің жауабынан бөлек өтеді.
5. Модельдің өзі CLI-де жұмыс істейді, бірақ TUZE-де қате болса, TUZE терезесінің қатесін қараңыз және чаттағы хабарламаны жіберіңіз.

**Ескерту:** 20B моделі үшін тек файл өлшемі (13 ГБ) ғана емес, қосымша RAM және контекст жады керек. Компьютерде RAM жетпесе, шағын модель пайдалану қажет болуы мүмкін.
