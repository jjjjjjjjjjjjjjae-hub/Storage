# Storage — TUZE / Qwen3 chat history

Бұл қоймада әр чат **бір ғана JSON файлында** сақталады. Чаттар бір-бірімен араласпайды.

```text
Storage/
└── chats/
    ├── chat_001.json
    ├── chat_002.json
    └── ...
```

Әр файлдың құрылымы:

```json
{
  "schema_version": 1,
  "id": "<unique-chat-uuid>",
  "filename": "chat_001.json",
  "title": "Әңгіме атауы",
  "created_at": "<ISO timestamp>",
  "updated_at": "<ISO timestamp>",
  "messages": [
    {
      "id": "<unique-message-uuid>",
      "role": "user",
      "content": "Сәлем",
      "created_at": "<ISO timestamp>"
    }
  ]
}
```

**Сақтау тәртібі:** хабарлама тек өзінің файлындағы `messages` тізіміне қосылады; алдымен ноутбукқа атомарлық түрде сақталады, кейін GitHub-пен синхрондалады. GitHub-та ескі жазбалар SHA арқылы тексеріліп, қайшылық болса хабарлама UUID-лері бойынша біріктіріледі. Бөлек чаттар бір файл атауын алса, біреуі жаңа атауға көшіріледі, ешбір чаттың үстінен жазылмайды.

**Қауіпсіздік:** бұл репозиторий public. Құпия, жеке ақпарат бар чаттарды мұнда жүктемеңіз; жеке әңгімелерді сақтау үшін қойманы Private етіп өзгертіңіз. GitHub токенін ешқашан бұл репозиторийге жүктемеңіз.

`chats/.gitkeep` — әзірге бос бумаға арналған белгі; шынайы `chat_001.json` алғашқы чат ашылғанда ғана жасалады.
